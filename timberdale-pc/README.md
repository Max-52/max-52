# Timberdale — версия для ПК (установщик .exe)

Ничего ставить на компьютер не нужно: установщик для Windows соберёт бесплатный сервис GitHub Actions.

1. Зарегистрируйся на github.com и создай новый репозиторий (кнопка New).
2. Загрузи туда ВСЁ содержимое этой папки (Add file → Upload files). Папка `.github` скрытая; если она не загрузилась, нажми Add file → Create new file, впиши путь `.github/workflows/build-windows.yml` и вставь текст из файла `build-windows.yml.backup`.
3. Открой вкладку Actions → Build Windows installer → Run workflow (или дождись автозапуска).
4. Через 3-6 минут открой готовый запуск, в разделе Artifacts скачай `Timberdale-Setup`. Внутри zip будет `Timberdale-Setup-1.0.0.exe`.
5. Запусти его: выбери папку, нажми «Установить». Появятся ярлыки на рабочем столе и в меню «Пуск».

Если Windows пишет «Система Windows защитила ваш компьютер» — это потому что у установщика нет платной подписи. Нажми «Подробнее» → «Выполнить в любом случае».

Управление на ПК: WASD — ходить, Shift — бег, E — рубить, Пробел или левая кнопка мыши — бить, F — сажать, T — факел, G — телепорт, F11 — полный экран. Сенсорные кнопки на ПК скрыты.

Хочешь без установки? Просто открой файл index.html в Chrome или Edge: игра работает и так.
